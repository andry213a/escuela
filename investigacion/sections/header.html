El efecto Barnum: por que las descripciones vagas parecen personales

El efecto Barnum es la tendencia a aceptar como precisas descripciones generales que podrian aplicarse a casi cualquier persona. Se le conoce tambien como efecto Forer.

Cuando una frase es lo bastante ambigua, nuestro cerebro completa los huecos con experiencias propias y se siente comprendido.

Como se nota en la vida diaria

  • Horoscopos: mensajes positivos y generales que suenan muy personales.
  • Tests virales: resultados "hechos para ti" que usan frases ambiguas.
  • Lecturas frias: tecnicas para parecer que se conocen detalles intimos.
